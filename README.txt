Assignment: Stacks, Queues, and Deques

Dscription:
This assignment implements six data structures in C++17:

1. Array-based stack
2. Linked-list stack
3. Array-based queue
4. Linked-list queue
5. Array-based deque
6. Linked-list deque

The program demonstrates insertion and removal operations, checks for empty structures, and tests each implementation with a sequence of operations. It also demonstrates how arrays and linked lists can be used to build these data structures without using the standard library containers that directly implement them.

The array-based structures have a fixed capacity of 100 elements. If an array is full, additional insertions are ignored. Linked-list structures allocate nodes dynamically as needed.

The main() function tests all six data structures with insertion and removal operations, including attempts to remove elements from empty structures.


How to Compile and Run:

Visual Studio:
1. Open the project in Visual Studio.
2. Make sure the .cpp file is included in the project.
3. Set the project as the startup project.
4. Select Build, Build Solution
5. Press Ctrl + F5 to run without debugging.

If you have a C++ compiler that supports C++17, open a terminal in the directory containing the source file and run.
